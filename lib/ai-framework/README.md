# VAIOS Core Foundation (Milestone 1)

This folder contains contract-first foundations for VAIOS.

Scope for Milestone 1 Batch 1:
- Module boundaries
- Interface contracts
- Shared types
- Error taxonomy
- Configuration contracts
- Event taxonomy and envelope contracts
- Trace and correlation identity contracts
- Decision Ledger contracts
- Business Brain contracts
- Domain Pack contracts
- Security boundary contracts
- Feature flag contracts
- Testing contracts

Out of scope for this batch:
- Runtime implementations
- Product-specific behaviors
- AI generation logic
- Domain Pack implementations
