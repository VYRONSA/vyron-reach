# VYRON REACH — FINAL COMPLETION PACK

## Final product direction

VYRON REACH is the internal revenue command centre used to grow VYRON CORE.

The app should stay focused on:

1. Command Centre
2. Pipeline
3. Leads
4. Campaigns
5. Reports
6. System Settings

Anything outside those pages should stay hidden until real usage proves it is needed.
